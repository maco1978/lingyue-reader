# 聆阅看书 M3.1 — 搭子对话能力增强设计规格

- 日期：2026-11-27
- 状态：设计已确认，待转实施计划

## 目标

在现有读书搭子（M3）基础上增加两项**对话能力**，不引入新产出物页面：

1. **章节总结**：一键总结当前章节，结果留在对话流
2. **划线问答**：把用户手动粘贴的划线句子带入提问上下文

明确不做：读书报告、人物关系图（token 消耗大，用户决定搁置）；小朋友模式；Nano 本地引擎。

## 设计

### 1. 章节总结

- ChatPanel 顶部加「总结本章」快捷按钮
- 点击 → 自动发出预设问题「请用 3-5 个要点总结当前章节」，走现有 `runAgent`，回答留在对话流
- 上下文复用 `buildContext`（已含当前章节片段），无需新增工具

### 2. 划线问答

- ChatPanel 输入区加一个可选「划线内容」输入框（可折叠/展开）
- 用户粘贴/输入书中句子后提交时，把划线内容拼进 question：
  `针对划线句子「<quote>」：<用户问题>`（若划线为空则原样提问）
- 划线内容仅用于本次提问，**不写入 chatHistory**（避免污染历史）
- 走同一 `runAgent`，无需改 AgentLoop

## 边界与约束

- 不修改 `BookState` / `Book` 等核心类型契约
- 不修改 `runAgent` / `buildContext` / `LLMProvider` 逻辑
- 只改 `src/ui/ChatPanel.tsx` 及其测试
- API Key 仍由用户自填（代码不硬编码）
- 回答保留「AI 生成」标记

## 验收

- TDD：新增 2-3 个测试（总结按钮文案与点击、划线输入框渲染、提交时 question 拼接）
- 全量测试通过（基线 77）
- `pnpm run build` 通过
